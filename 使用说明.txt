Agent 红绿灯 0.12.1 · Windows 10/11 x64

解压后双击 CodexLight.exe。无需安装，不需要 Python、Node 或额外运行库。
默认只有一盏不带字母的标准圆灯，自动对应一个 Agent。
支持 Codex、Cursor、豆包、WorkBuddy、DeepSeek Harness。

鼠标悬停：查看对应的 Agent 和状态。
单击灯：切回对应应用窗口，最小化时还原；多个窗口时先选择窗口。
右键灯：
  对应 Agent：自动跟随，或手动指定。
  样式：标准圆灯、圆圈灯、拟态圆灯、多孔圆灯、法阵圆灯，共五种。
  添加一盏灯：按需增加，默认仍是相同标准圆灯，最多 8 盏。
  删除这盏灯：仅删除当前灯，至少保留一盏。
  开机启动、退出红绿灯。

红色=运行中；黄色=等待原生回答/确认；绿色=本轮结束；灰色=中断或状态未知。
豆包暂不能区分正常结束和手动停止，两者均显示绿色。
自动灯保持正在执行或等待回答的任务，结束后保留约 2 秒再匹配其他任务。
初次匹配优先最近使用的运行中 Agent，否则优先等待回答、较新的运行任务。
没有活动任务时跟随最近使用的已打开 Agent；额外自动灯避免重复占用。
手动灯始终对应所选 Agent，应用未打开时灰灯，不换成其他应用。
绑定和样式会保存。新灯不继承其他灯的自定义样式。
样式只改变灯的外观，换样式不改绑定，换 Agent 不改样式。
旧方形、菱形、应用标识样式恢复标准圆灯，保留圆圈款及灯数量、绑定。
右键采用简洁圆角菜单，跟随系统明暗主题，勾选和样式预览放在右侧。
支持方向键、回车选择、Esc 或点击外部关闭。

单击仅定位应用窗口，不保证跳转具体聊天标签页。
Windows 可能将灯折叠在隐藏图标中，首次请按需要拖到时钟旁。
首次使用默认开机启动，可在右键菜单关闭，关闭后不会在下次启动时自动开启。升级保留已有设置。升级旧多灯版本会改为一盏自动圆灯。
安装到其他盘一般不影响识别；程序按当前 Windows 用户查找数据目录。
Cursor、WorkBuddy 首次发现时自动注册本机回调，保留并备份已有配置。
自定义数据目录、Agent 版本变化或特殊多实例配置可能需要调整。
DeepSeek 适配针对 Harness 桌面 Agent，不包含网页聊天。

程序仅本地读取状态，不上传聊天记录；设置位于 %LOCALAPPDATA%/CodexLight。
不要向别人发送该数据目录、runtime 目录或 Agent 的聊天数据。
EXE 尚未签名，Windows 可能显示未知发布者提示。

高级用法：--all（默认，可自动匹配全部支持的 Agent）；--codex / --cursor /
--doubao / --workbuddy / --deepseek（原固定单 Agent 模式）。切换模式前请先退出旧实例。
